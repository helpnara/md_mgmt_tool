| 간트차트 · 과제 간 의존성 | 이 도구의 목적은 **이력과 보고**다. 일정 관리 도구가 되려 하면 둘 다 어중간해진다 |
| 결재·승인 워크플로 | 사내 시스템이 이미 하는 일이다. 겹치면 이중 입력만 늘어난다 |
