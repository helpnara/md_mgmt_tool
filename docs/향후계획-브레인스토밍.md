## 7. 하지 않는 편이 낫다고 보는 것

고려했지만 **지금은 하지 말자**고 판단한 것들이다. 이유를 남겨 둔다.

| 항목 | 하지 않는 이유 |
|---|---|
| 구글독스식 실시간 공동 편집 | 파일이 원본이라는 이 도구의 근본 설계와 충돌한다. 얻는 것에 비해 잃는 것(단순함·이식성)이 크다 |
| 모바일 전용 앱 | 웹 반응형으로 충분하다. 진행일지 작성은 애초에 PC에서 하는 일이다 |
| 간트차트 · 과제 간 의존성 | 이 도구의 목적은 **이력과 보고**다. 일정 관리 도구가 되려 하면 둘 다 어중간해진다 |
| 결재·승인 워크플로 | 사내 시스템이 이미 하는 일이다. 겹치면 이중 입력만 늘어난다 |
| 자체 알림 메일 발송 | 사내 메일 정책에 묶인다. 화면 배너(T12)로 충분하다 |
