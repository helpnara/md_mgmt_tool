## 3. 이번에 한 것의 흐름

```text
초안 ──(기술 · 도구 → 도구 칸)──┐
AI 응답 ──(규칙 ①)──────────────┼─▶ 저장할 때 ② 동의어 맞춤 · 도구 옮김 ─▶ 남는 "사전에 없음"
사람 입력 ──(자동 완성 ③)───────┘                                              │
                                    ④ 역량 태그 정리함(팀 전체 · 제안) ◀───────┘
                                    ⑤ AI 로 맞추기 → 고르는 칸 채움 → 사람이 [적용]
```

* 정리함의 [적용]은 **사전 한 번 + 모든 경험의 태그 한 번**을 같이 바꾼다. 모두 먼저 검사하고(사전에 없는 대표 이름이면 아무것도 안 바꿈), 이전 버전이 남는다.
* AI 의 답은 **그대로 사전에 넣지 않는다** — 고르는 칸만 채우고 사람이 본다(71 · 3단계와 같은 원칙).
