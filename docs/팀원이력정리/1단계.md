## 1. 범위

| 한다 | 하지 않는다 |
|---|---|
| AI 응답 글 → 경험 블록 읽기(파서 규칙 1 ~ 15) | 파일 저장 · 색인 · 스키마 (2단계) |
| 블록 하나의 검사 — 필수 칸 · 값 모양 · 상태별 조건 · 확정 조건 1 ~ 4 | 정합성 X-01 ~ X-08 (다른 경험 · 담당과 역할이 필요 — 4단계) |
| 기간 읽기(`YYYY-MM` 두 끝) · 정량 성과의 기준 종류 **추정** | 역량 이름을 사전에 맞추기 (4단계) |
| 가상 시험 자료 다섯 + 시험 | 화면 · 끝점(API) · 배포본에 보이는 변화 — **0** |

## 3. 함수 모양

```python
KEYS = ("형식", "제목", "기간", "회사", "조직", "직위", "역할", "구분", "상황", "목표", "행동",
        "결과_정량", "결과_정성", "비즈니스_영향", "역량_기술", "역량_업무", "역량_리더십", "역량_문제해결",
        "교훈", "증빙", "확인_필요", "이어짐")          # 원본 3.1 의 21 + 이어짐(규칙 9)
LIST_KEYS = ("행동", "결과_정량", "증빙", "확인_필요")

@dataclass
class Quant:            # 지표 · 값 · 기준 · 시점 + 추정한 기준 종류 + 경고

def confirm_ready(block: ParsedBlock) -> list[str]: ...               # 확정 조건 1 ~ 4 중 못 맞춘 것
def guess_baseline_kind(baseline: str) -> str: ...                    # 낱말 목록으로 추정
```

## 4. 원본에 없는 세부 — 착수 전에 정할 것

원본 규칙(v0.2)은 실험 01 의 48 블록을 사람이 읽어 정했다. 코드로 옮기면 아래가 비어 있다.
정한 것은 원본(`docs/spec/context_file.md` 3.3)에 **v0.3 으로 돌려 적는다** — 원본이 형식의 주인이다(README 6절).

| # | 빈 곳 | 추천 |
|---|---|---|
| ① | **블록이 어디서 끝나나** — 원본은 "다음 `형식:` 줄 직전까지". AI 가 마지막 블록 뒤에 설명 글을 붙이면 그 글이 블록에 섞인다 | 펜스가 열렸으면 **닫는 펜스까지**. 펜스가 없으면 다음 `형식:` 줄, 또는 **빈 줄 뒤에 키도 목록도 아닌 줄**이 오면 거기서 끝(그 뒤는 블록 밖 설명 — 무시하고 수만 센다) |
| ② | **이어지는 줄** — 키도 `- ` 목록도 아닌 줄(AI 가 긴 상황을 두 줄로 쓴 것) | 빈 줄 전까지는 **바로 위 키의 값에 이어 붙인다**. 규칙 13(못 읽은 줄)은 키 앞에 오는 줄 · 블록 첫머리의 엉뚱한 줄에만 |
| ③ | **키로 볼 조건** — 값 안의 "참고: …" · "단, 기준: …" 을 키로 오인 | 첫 `:` 앞을 정규화해 **알려진 키**면 키. 아니면 **8자 이하 · 공백 하나 이하 · 문장부호 없음**일 때만 미분류 키(규칙 6), 그 밖은 이어지는 줄(②) |
| ④ | **기간 모양** — `2026-03 ~ 2026-09` 밖의 것(`2016 ~ 2017` · `2026.03-2026.09` · `2026년 3월 ~ 9월` · 물결표 없음 · `현재`) | 허용 목록으로 `YYYY-MM`(또는 `YYYY`) 두 끝. `현재` · `진행 중` 은 끝 비움. 못 읽으면 원문 보관 + 경고(검사에서 X-07 의 재료) |
| ⑤ | **중복 후보(규칙 14)의 "비슷함"** | 정규화한 제목이 같거나 **유사도 0.8 이상**(difflib), 또는 기간이 같고 정량 값 하나가 같으면 |
| ⑥ | **교훈의 출처 표시** — 원본 04 는 `lesson_source` 칸을 따로 두고, 이관판은 교훈 안에 그대로 | 파서가 끝의 괄호 출처 "(…)" 를 `lesson_source` 로 **떼어 두되** 교훈 원문도 보존 |
| ⑦ | **증빙 종류 `이미지`** — 원본 3.7 엔 있고 이관판 데이터모델엔 빠짐 | 넣는다(첨부 그림). 데이터모델 3절에 한 줄 더한다 |
| ⑧ | **기준 종류 추정** 낱말 | 비교 = `대비 · 기존 · 전년 · 이전 · →`, 집계 = `누적 · 연간 · 총 · 정원 · 건수 · 월`, 조건 = `가정 · 조건 · 시`, 그 밖 · `기준 없음` = 미확인. 규칙 12 의 "비교 기준인가?" 질문은 미확인 · 집계 · 조건에 붙인다 |

(원본의 `merged_into` — 두 경험을 합칠 때 — 는 저장이 생기는 2단계에서 본다.)

## 5. 시험 목록

**규칙마다 하나 이상** (규칙 번호 = [응답형식](응답형식.md) 3절)

| 규칙 | 시험 |
|---|---|
| 1 | 펜스 있음 · 없음 · 한 응답에 블록 셋(빈 줄 없이 이어짐) — 블록 수 |
| 2 | 블록 0개 → 빈 결과 + 안내 문구 + 원문 그대로 |
| 3 | 줄 끝 `[span_1](start_span)[span_1](end_span)` 이 값에서 사라지고 지운 수를 센다 |
| 4 | U+FFFC 글머리표 · 다른 제어 문자 |
| 5 | 값 안의 `:` · `"` · `#` 이 그대로 |
| 6 | `결과 정량` = `결과_정량` · 모르는 키는 미분류 |
| 7 | 교훈 아래 `- ` 목록 → 줄바꿈 결합 · `/` 이음 · 출처 표시 보존 |
| 8 | 빈 값 여섯(빈 글 · `-` · 해당 없음 · 미상 · 없음 · 확인 필요) → 빈 값, 원래 표기 보존 |
| 9 | `이어짐: E-027` · `E-027?` · `없음` |
| 10 | 정량 네 칸 · 세 칸 · 두 칸(경고) |
| 11 | `기준: 기준 없음` · `시점: 2026` 의 접두어 |
| 12 | 기준 없음 · 미상 · 빈 칸 → "기준 없음", 집계 단위("연간 누적") · 조건 · 기간이 오면 질문 표시 |
| 13 | 못 읽은 줄의 줄 번호 · 원문 · 사유, 나머지 칸은 채워짐 |
| 14 | 같은 제목 · 비슷한 제목 · 같은 기간 + 같은 값 → 중복 쌍 |
| 15 | 결과에 원문 전체가 실린다(저장은 2단계 — 여기선 돌려주기만) |

**자료 다섯** — 블록 수 · 칸 · 경고를 통째로 맞춘다([응답형식 5절](응답형식.md)).
**정한 것 ① ~ ⑧** — 각각 하나 이상.
**검사(check)** — 상태별 필수 칸 · `E-nnn` 모양 · 구분 두 값 · 기간 · 확정 조건 1 ~ 4(5 는 4단계) · 기준 종류 미확인이 남으면 확정 못 함.
**규칙 끄기** — `PARSE_STEPS` 에서 하나씩 빼고 자료 다섯을 다시 읽으면 **결과가 달라져야 한다**(달라지지 않으면 그 규칙을 시험하는 자료가 없다는 뜻). 한 시험으로 모든 단계를 돈다.

예상 크기 — 코드 400줄 안팎, 시험 60건 안팎.
