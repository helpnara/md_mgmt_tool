회사:
조직:
직위:
역할: 판정 기준 정리와 시범 적용은 본인, 설비 연동은 설비팀

## 2. 블록 규칙 (프롬프트에 그대로 들어간다)

1. 블록은 ` ```slow-way ` 로 시작하고 ` ``` ` 로 끝낸다. 블록 밖 설명은 자유이며 무시한다.
2. 첫 줄은 `형식: slow-way-experience/0.1`.
3. 한 줄에 `키: 값`. 키는 위 이름만. 값이 없으면 키만 남긴다. 키를 빼지 않는다.
4. 목록 키(행동 · 결과_정량 · 증빙 · 확인_필요)는 다음 줄부터 `- ` 로 나열한다.
5. `결과_정량` 은 `지표 | 값 | 기준: … | 시점: …` 네 칸. 기준을 모르면 `기준 없음`. 원문에 없는 수치를 만들지 않는다.
6. 원문에 없는 내용은 추정하지 않는다. 비면 `확인_필요` 에 질문으로.
7. 경험이 여럿이면 블록도 여럿. 블록 하나에 경험 하나.

## 3. 파서 규칙 (실험 01 로 확정)

**블록 찾기**
1. 블록 시작은 `형식: slow-way-experience/0.1` 줄(앞뒤 공백 · 펜스 무시). 다음 `형식:` 줄 앞까지가 한 블록. **펜스는 있으면 보조, 없어도 된다** — 한 서비스는 펜스를 아예 출력하지 않았다.
2. 블록이 하나도 없으면 응답 전체를 원문으로 보관하고 "형식 블록이 없습니다. 프롬프트를 다시 붙여 넣으세요" 를 안내한다.

**전처리**
3. 줄 끝의 인용 표식 `\[span_\d+\]\((start|end)_span\)` 을 지운다(한 서비스의 복사 단추가 근거 표식을 그대로 내보낸다).
4. U+FFFC 같은 제어 · 치환 문자를 지운다(글머리표가 이 문자로 깨져 온다).
5. 줄 단위로 읽는다. YAML · JSON 라이브러리를 쓰지 않는다 — 한국어 값에 콜론 · 따옴표 · `#` 이 흔하다.

**키와 값**
6. 키는 줄의 첫 `:` 앞. 공백 · 밑줄을 지우고 비교한다(`결과 정량` = `결과_정량`). 모르는 키는 버리지 않고 "미분류"로 보여 준다.
7. 한 줄 키(상황 · 목표 · 결과_정성 · 비즈니스_영향 · 역량_* · 교훈) 아래 `- ` 목록이 와도 받아서 줄바꿈으로 잇는다. 교훈의 `/` 이음과 출처 표시는 그대로 둔다.
8. 빈 값: 빈 글 · `-` 하나 · `해당 없음` · `미상` · `없음` · `확인 필요` 는 빈 값으로 저장하되 원래 표기는 남긴다.
9. `이어짐: E-nnn` · `E-nnn?` · `없음` 을 알아본다(기존 경험에 이어 붙일 때).

**정량 성과**
10. `|` 로 나눈다. 네 칸이면 지표 · 값 · 기준 · 시점, 세 칸이면 시점 없음, 두 칸 이하면 전부 지표 칸에 넣고 경고.
11. 기준 칸의 `기준:` · 시점 칸의 `시점:` 접두어를 지운다("기준: 기준 없음" 이 흔하다).
12. 기준이 `기준 없음` · `미상` · 비었으면 "기준 없음". 기준 칸에 집계 단위 · 조건 · 기간("연간 누적", "7주간", "격주")이 오면 확정 화면에서 "비교 기준인가?" 를 묻는다.

**오류**
13. 못 읽은 줄은 줄 번호와 원문을 보여 주고 나머지는 채운다. 블록 전체를 버리지 않는다.
14. 같은 응답 안에서 제목 · 기간 · 정량 값이 비슷한 블록 쌍을 중복 후보로 표시한다.
15. 읽은 결과와 함께 응답 원문 전체를 보관한다(`people/<이름>/experiences/responses/`).

## 4. 함수 모양 (1단계)

```python
def parse(text: str) -> ParseResult: ...

@dataclass
class ParsedBlock:
    index: int                       # 응답 안 순서
    fields: dict[str, str]           # 한 줄 키 (정규화한 키 이름)
    lists: dict[str, list[str]]      # 행동 · 증빙 · 확인_필요
    quants: list[Quant]              # 지표 · 값 · 기준 · 시점 + 경고
    continues: str | None            # "E-027" · "E-027?" · None
    unknown: dict[str, str]          # 미분류 키
    bad_lines: list[BadLine]         # (줄 번호, 원문, 사유)

@dataclass
class ParseResult:
    blocks: list[ParsedBlock]
    found_fence: bool
    stripped_markers: int            # 지운 인용 표식 수
    duplicates: list[tuple[int, int]]  # 중복 후보 쌍 (규칙 14)
```

파일 · DB 를 모른다. 역량 이름 맞추기와 저장은 바깥(2 · 3단계 서비스)에서 한다.

## 5. 가상 시험 자료 (1단계)

실제 AI 응답은 저장소에 넣지 않는다. 실험 01 에서 본 **형식 변형을 하나씩 재현한 가상 응답**을 만든다.

| 자료 | 재현하는 변형 |
|---|---|
| `fenced.md` | 펜스 있음, 빈 목록 `-`, 교훈 `/` 이음과 출처 표시 |
| `no_fence.md` | 펜스 없음, 블록이 빈 줄 없이 이어짐, "기준: 기준 없음" 반복, 교훈이 목록 |
| `span_markers.md` | 줄 끝마다 인용 표식, 한 줄 키 아래 목록, "- 해당 없음" |
| `broken.md` | 정량 두 칸, 모르는 키, U+FFFC 글머리표, 물결표 없는 기간, 블록 0개 응답 |
| `continued.md` | 나눠 붙여 넣은 두 응답, 같은 제목 블록 재등장 |

시험: 규칙 15개 각각 + 자료 다섯의 블록 수 · 필드 · 경고. 시험을 쓴 뒤 규칙을 하나씩 꺼서 **실패하는지 본다**(LESSONS ⑥).
